# Fuzzy title matching

Media Voyage adds PostgreSQL `pg_trgm` whole-title similarity as an equal third candidate stream in hybrid library search, while preserving the existing full-text and semantic branches. The same title predicate—substring match or a configurable trigram match beginning at five characters with a `0.3` similarity cutoff—is used by the Filter Card and lightweight title lookup; the latter therefore also improves Command Palette and collection-item title selection without changing their alphabetical ordering. The `pg_trgm` extension is enabled once outside Drizzle, and Drizzle Kit pushes the GiST title index. The cutoff matches PostgreSQL's default `pg_trgm.similarity_threshold` and follows its strict `similarity > threshold` behavior; if it is lowered later, that database setting must be lowered as well so the index-backed `%` prefilter does not exclude valid matches.
